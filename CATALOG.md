# Profile catalog

Generated by `python tools/nclib.py catalog`. Each table is the numpad as it sits on your desk; a key shows its tap action, then `(hold)` and `(double)` actions. Keys with no action are dimmed. ⚠ marks actions that run programs, press keys for you or power the PC off.

## Blender

Blender with a working numpad: while Blender is focused the keys send Blender's numpad view keys (front, right, top, camera, perspective, frame selected, orbit, zoom). Hold 1, 3 or 7 for the opposite view (back, left, bottom). Enter toggles edit mode and Backspace undoes. Keep Blender's Emulate Numpad preference off.

- **File:** [`profiles/official/blender.json`](profiles/official/blender.json) · **For:** `blender`, `Blender`
- **Works on:** windows, linux
- **⚠ Runs:** `press_keys`
